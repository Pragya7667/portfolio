# Pragya Soni — Personal Portfolio Website

## Setup & Usage
1. Extract all files from this ZIP archive into a single folder.
2. Place your resume PDF as `resume.pdf` in the root folder so the **Download Resume** button works immediately.
3. Open `index.html` in any browser or deploy directly to GitHub Pages, Vercel, or Netlify.
4. The contact form works immediately out of the box (opens pre-filled email draft to `sonipragya7667@gmail.com` + provides a direct Gmail Web link).
